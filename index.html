Trūkst datubāzes pievienojums

Šis kazīns glabā kontus, JG balansus un reitingus Supabase projekta datubāzē, un tur arī pulkā reāllaika istabas. Bez tā spēlēt nevar — tāpēc nevis liekoties, ka parole ir nepareiza, mēs rādām šo ekrānu.

  1. Sapnā supabase.com un atver savu projektu. Ja nav — New project, bezmaksas plāns, 2 minūtes.
  2. Settings → API: nokopē Project URL un anon public atslēgu.
  3. Atver index.html, atrod rindi SB_URL un SB_KEY un ielīmē savas vērtības.
  4. Atpakaļ Supabase: SQL Editor → ielīmē setup-schema.sql → Run.
  5. Authentication → Providers → Email: izslēdz Confirm email un saglabā.

Pēc tam pārlādē lapu un reģistrējies. Ja kaut kas tomēr neiet, atver pārlūka konsoli (F12) — tur redzēs precīzu kļūdu.
